# Consumer Funnel & Experimentation Analytics — Fumato Reorder

NextLeap team product-analytics case focused on reducing friction when a user wants to repeat a previous food order.

This is a **case-study repository**, not a deployed production application.

## Problem
Users who want to repeat a previous order often have to reconstruct the basket manually.

## Work completed
- Mapped the repeat-order journey through order history, basket review, editing and confirmation.
- Compared alternative entry points including navigation, home page, past orders and nudges.
- Scoped a focused reorder MVP.
- Designed exception states for restaurant closed, item unavailable, price changed and invalid prior customisation.
- Defined experiment outcomes and guardrails around conversion, time-to-complete and reliability.

See `case_study.md` for the detailed analytical framework.
